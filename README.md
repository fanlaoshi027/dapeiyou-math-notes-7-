# 2026七年级《大培优》数学知识笔记

本项目用于整理《2026七年级〈大培优〉数学》各讲知识点，并制作成适合小红书、抖音发布及打印复习的双图资料。

## 固定制作规范

- **一讲一份**：原则上每一讲作为一个独立知识单元。
- **每讲两张图**：
  1. 实物手写效果图：自然手写、真实桌面/纸张质感。
  2. 正面打印版：正面、平整、清晰，便于打印。
- **两张图内容完全一致**：知识点、公式、例题、解题过程、图示和易错点不得自行增删改写。
- **标题**：贴合教材核心内容，同时尽量简洁、有吸引力。
- **内容依据**：以本书对应讲次和具体页面为准，不用教材外知识替换或扩充原内容。
- **发布文案**：每讲配套标题、介绍和 #标签。

## 目录结构

```text
01-第1讲-有理数五大概念/
02-第2讲-创新题型/
03-第3讲-有理数四则运算/
...
```

后续全部讲次按同一规范持续整理。
